# Lab10_2_RealApiLogin

A Flutter project demonstrating user authentication using a real REST API (DummyJSON API at `https://dummyjson.com/auth/login`).

## How to Run

1. Navigate to the project folder:
   ```bash
   cd Lab10_2_RealApiLogin
   ```
2. Retrieve packages:
   ```bash
   flutter pub get
   ```
3. Run the application:
   ```bash
   flutter run
   ```
