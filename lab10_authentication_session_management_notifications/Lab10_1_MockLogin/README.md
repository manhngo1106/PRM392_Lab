# Lab10_1_MockLogin

A Flutter project demonstrating a Mock Login screen with complete validation and simulated asynchronous delay.

## How to Run

1. Navigate to the project folder:
   ```bash
   cd Lab10_1_MockLogin
   ```
2. Retrieve packages:
   ```bash
   flutter pub get
   ```
3. Run the application:
   ```bash
   flutter run
   ```
